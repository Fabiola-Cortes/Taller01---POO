## Descripción del Proyecto

El proyecto consiste en un sistema desarrollado en Java para gestionar las solicitudes de alumnos que desean ingresar a los paralelos C1 y C2.
El sistema toma la lista oficial (Alumnos.txt) y la compara contra quienes intentan entrar (Solicitudes.txt) para admitir o rechazar personas automáticamente. También permite a los ayudantes hacer inscripciones manuales por nombre o RUT, administrar cambios en el curso como cambiar de paralelo, eliminar o agregar alumnos actualizando el archivo y generar reportes versionados junto con estadísticas del proceso.

## Instrucciones de Ejecución

1. Abrir el proyecto en Eclipse (o cualquier IDE de Java compatible).
2. Asegurarse de que los archivos de datos (`Alumnos.txt` y `Solicitudes.txt`) estén ubicados en la carpeta raíz del proyecto.
3. Compilar y ejecutar la clase principal `Taller1.java`.
